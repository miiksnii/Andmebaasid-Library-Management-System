Raamatukogu ja pangaserveri kiire test

Käivita enne testimist pangaserver pordil 4001 ja raamatukogu server pordil 4000. Siis vajuta nuppe ülevalt alla.

Pangaserver kasutab PostgreSQL andmebaasi bank. Raamatukogu server kasutab PostgreSQL andmebaasi library.

3. Maksa tellimus

4. Testi pärast maksmist

Need tegevused kirjutavad raamatukogu library andmebaasi. Need töötavad alles siis, kui tellimus on makstud ja token olemas.
